# Membench v0.1.1

Release candidate notes. This file does not create or authorize a tag or deployment.

## Included

- Public, adapter-free CLI paths for importing, exploring, promoting, and inspecting portable
  records.
- Symbiotic Memory adapter migration to `EngineConfig`, with the exact private dependency and
  its four-package lock identity pinned.
- Target-matched zvec source packaging and provenance verification in the protected adapter
  build.
- OSS leaderboard landing backed by the reviewed canonical record set.

The bundled record set is unchanged from v0.1.0. Its records digest is
`4c42a71f61f6b2e126800bd581754b3ceed70ef06dd0ce98b24aa008477f5d74`.

## Scope boundary

The `longmemeval-v2-text` path remains experimental. This release does not claim an official
LongMemEval-V2 result and must not promote those runs into the ranked leaderboard.

## Publication gate

Before creating `v0.1.1`, repin Membench to the merged Symbiotic Memory consumer-ledger revision
and require all six protected jobs to pass on that exact Membench head. Then run:

```sh
./scripts/check-release-metadata.sh --tag v0.1.1
./scripts/check-leaderboard-snapshot.sh
```

Build and deploy `dashboard/dist/` only from the resulting `refs/tags/v0.1.1` checkout. The
release metadata and leaderboard records digest must match the deployed artifact.
