membench v2 — the memory-system cockpit

An agnostic benchmark + debug tool for memory / hybrid / agentic systems. Any adapter (symbiotic-memory, mem0, zep…) × any benchmark (LongMemEval, multimodal…) plugs in via a typed manifest; the host renders knobs, queues, traces, and coverage generically. Four persona workspaces — click any card, then use the F1–F4 bar to move between them.
